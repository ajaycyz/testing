# Law Firm Website Prototype

Static multi-page prototype structured to mirror a premium law-firm homepage and inner-page flow, ready to port into WordPress builders.

## Pages
- `index.html` (homepage)
- `about.html`
- `practice-area.html`
- `contact.html`

## WordPress build mapping
- Header + footer templates can be global parts.
- Homepage sections can be created as reusable block patterns.
- Inner pages align with About / Practice Area / Contact page templates.
- Styling is centralized in `styles.css` for quick theme customization.
