# Law Firm Website Prototype (WordPress-Ready Structure)

This prototype mirrors the requested professional layout and visual hierarchy inspired by the provided reference site, with law-firm-specific editable content.

## Included pages
- `index.html` (homepage sections)
- `about.html`
- `practice-areas.html`
- `our-team.html`
- `contact.html`
- `styles.css`

## WordPress mapping
- Header / Footer -> Theme template parts
- Each section block -> Elementor sections or Gutenberg groups/columns
- Practice cards and team cards -> reusable block patterns
- CTA and contact blocks -> reusable global sections

## Local preview
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`.
